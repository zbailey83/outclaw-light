What slash commands does Claude Code support?

Last verified: July 2026 · 2 min read
QUICK ANSWER

Claude Code supports command-line interface utility slash commands: '/init' to bootstrap directories, '/config' to set settings, '/mcp' to manage server connectors, '/clear' to purge console history, and '/exit' to terminate.

Slash Command Reference

Command Action / Description
/init Initializes workspace environment guidelines for Claude.
/config Lists, gets, or updates configuration settings.
/mcp Lists and registers Model Context Protocol servers.
/clear Clears chat history and releases token memory context.
/exit Exits the Claude Code session.
Verified against: Claude Code CLI v0.2.5
