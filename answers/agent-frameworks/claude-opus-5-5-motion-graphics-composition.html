How do you build programmatic motion graphics with Claude Opus 5.5 and HyperFrames?

Last verified: October 2026 · 2 min read
QUICK ANSWER

To build programmatic motion graphics with Claude Opus 5.5 and HyperFrames, scaffold a project with npx hyperframes init, prompt Opus 5.5 to synthesize a single paused master GSAP timeline (window.__timelines = [master]), enforce Cartesian SVG geometry with no non-deterministic APIs, and render headless frames via hyperframes render.

Building Programmatic Motion Graphics

  1. Initialize Project: Run npx hyperframes init videos/my-motion --non-interactive to scaffold the video directory.
  2. Enforce Master Timeline Contract: Require Opus 5.5 to construct a single paused master timeline: const master = gsap.timeline({ paused: true }); window.__timelines = [master]; window.__hfSeek = (t) => master.time(t);
  3. Eliminate Non-Determinism: Ban Math.random(), Date.now(), and performance.now(). Derive all procedural variance directly from frame index t = frame / fps.
  4. Pre-Calculate Geometry: Compute all bounding coordinates during setup. Animate only GPU transform properties (x, y, scale, rotation, opacity) to prevent layout thrashing.
  5. Render to MP4 or Transparent WebM: Execute hyperframes render (or pass --format webm --codec vp9 for transparent alpha overlays).
